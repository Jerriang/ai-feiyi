# PRD：遗境焕活（成品级 MVP）

## 1. 产品定位

- 产品名称：遗境焕活
- 产品定位：地方非遗场景的 AI 故事化导览与传播转化平台
- 一句话定义：不是资料展示页，而是“能看、能逛、能生成、能传播”的非遗体验产品。

## 2. 目标用户与价值

### 2.1 游客
- 快速理解非遗项目是什么
- 不阅读冗长文本，获得导览式体验
- 体验后可生成可分享内容

### 2.2 学生/年轻用户
- 喜欢故事化、视觉化、轻互动
- 希望有打卡感、成就感和社媒表达价值

### 2.3 场馆/运营方
- 低成本上新与维护内容
- 可查看数据并优化传播策略
- 不依赖复杂硬件即可运行

## 3. MVP 功能范围

### 3.1 用户端
1. 首页与主题入口
2. 非遗详情页（结构化知识）
3. AI 故事化导览页（文本 + 语音）
4. 个性化路线推荐页（可解释可编辑）
5. 纪念海报生成页（可预览下载分享）

### 3.2 后台端
1. 内容管理（草稿/审核/发布/下线）
2. 导览脚本管理（版本化）
3. 模板管理（海报模板）
4. 数据看板（浏览、停留、生成、分享）
5. 审计日志（关键操作可追溯）

## 4. 核心用户流程

### 流程 A：首次进入
首页 → 选择主题 → 系统简介 → 开始体验

### 流程 B：导览体验
选择主题 → AI 故事讲解 → 互动提问 → 下一段导览

### 流程 C：路线推荐
输入时间与偏好 → 生成路线 → 用户调整 → 执行路线

### 流程 D：纪念生成
完成体验 → 选模板 → 自动生成 → 预览 → 下载/分享

### 流程 E：后台运营
登录后台 → 录入/审核内容 → 发布 → 查看数据 → 优化

## 5. 详细需求（MVP）

### 5.1 首页与导览入口
- 3 秒内理解产品价值
- CTA：开始导览 / 智能推荐 / 生成纪念内容
- 游客模式可直接体验，不强制注册

### 5.2 非遗知识库
- 标准字段：名称、类别、背景、工艺流程、寓意、传承人、体验方式、素材
- 标签：地域、年代、工艺类型、适龄、推荐时长、热度
- 状态流转：draft → reviewing → published → archived

### 5.3 AI 故事化导览
- 风格：历史叙事 / 游客陪伴 / 儿童科普 / 文艺沉浸
- 分段：开场、核心讲解、互动问题、延伸知识、结尾
- 约束：事实白名单 + 术语表 + 来源片段引用
- 兜底：AI 异常时返回规则化讲解稿

### 5.4 个性化路线推荐
- 输入：停留时长、兴趣、出行类型、首次体验、偏好类型
- 输出：路线节点、每站时长、推荐理由、可跳过项
- 交互：用户可增删节点并重算时长

### 5.5 AIGC 纪念海报
- 输入：用户路线、浏览行为、偏好、上传素材
- 模板：国风 / 文艺 / 年轻社媒
- 输出：统一排版，支持预览、下载、分享、二次编辑

## 6. 非功能需求（成品级）

### 6.1 性能
- 首屏 ≤ 3 秒
- 页面切换 ≤ 1 秒
- AI 文本生成 3–8 秒（P95）

### 6.2 可用性
- 新用户 30 秒内知道如何开始
- 核心主链路 ≤ 3 次关键点击进入
- 所有关键操作有明确反馈状态

### 6.3 安全
- JWT + RBAC 权限
- 输入校验、防 SQL 注入、防 XSS、防越权
- 敏感字段加密（手机号、邮箱、设备 ID）
- 文件上传类型/体积/MIME 校验
- AI 输出合规过滤（涉政/涉黄/歧视/虚构史实）

### 6.4 稳定性
- AI 失败兜底
- 外部服务超时熔断重试
- 全链路日志与 trace-id

### 6.5 可扩展
- 城市、项目、模板、模型可热扩展
- 支持未来接入小程序/H5/触摸屏

## 7. 关键指标（验收）

- 理解度提升：任务后测正确率较前测提升 ≥ 20%
- 互动深度：人均导览停留时长 ≥ 6 分钟
- 传播意愿：纪念内容生成率 ≥ 35%，分享率 ≥ 15%
- 稳定性：核心接口成功率 ≥ 99.5%

## 8. 版本边界说明

第一版仅覆盖：
- 1 个城市
- 2–3 个非遗项目
- 1 条完整导览主链路
- 1 套核心海报模板体系

用于答辩演示、用户测试与后续迭代依据。
