# 测试与验收清单

## 1. 功能验收

- 首页可进入主题页，CTA 明确可用
- 用户可完成：主题选择 → 导览 → 路线 → 海报生成 → 分享
- 后台可完成：录入 → 审核 → 发布 → 下线

## 2. 体验验收

- 首次用户 30 秒内可开始体验
- AI 导览分段清晰、语义连贯
- 纪念海报具备可分享美感

## 3. 技术验收

- 核心接口成功率 ≥ 99.5%
- 首屏加载 ≤ 3 秒
- AI 文本响应 P95 ≤ 8 秒
- 无严重漏洞（越权、注入、XSS）
- 日志具备可追踪 request_id

## 4. 研究验收

- 问卷与访谈流程可执行
- 可用性测试能回收行为数据
- 能验证对理解度、参与度、传播意愿的正向影响

## 5. 回归测试建议

### 5.1 冒烟用例
1. 游客模式进入并完成单次导览
2. 路线推荐并手动调整成功
3. 海报生成、预览、下载成功
4. 后台发布内容后前台可见

### 5.2 异常用例
1. AI 服务超时，系统返回兜底讲解
2. 上传非法文件类型被拒绝
3. 无权限账号访问后台被拦截
4. 高并发下接口限流与降级生效
